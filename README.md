# software.kunev.dev

Учебен сайт за паралелка **„Разработка на софтуер“** (професия код 061303, направление 0613) — материали по специалните предмети, подредени по класове, раздели, теми и седмици според официалната учебна програма.

**Продукция:** [software.kunev.dev](https://software.kunev.dev) (Vercel, deploy при push към `main`)

## Стек

- [Next.js](https://nextjs.org/) (App Router, статичен рендер)
- [Tailwind CSS 4](https://tailwindcss.com/) — cyber teal dark тема (токени в `src/app/globals.css`)
- TypeScript, без база данни и без auth — цялото съдържание е публично и статично

## Структура на съдържанието

Учебната програма се пази като структурирани TypeScript данни, не в JSX. Дългите учебни текстове са MDX файлове (хибриден модел):

```
src/data/types.ts        # модел: клас → предмет → раздел → тема → седмици + тест/задачи/домашни
src/data/curriculum.ts   # програмата: VIII клас · „Дигитални технологии“ (Раздели I–II, Теми 1–6)
src/data/materials/      # материали по теми: тест (Quiz), практически задачи (PracticeTask) и домашна работа по седмици (HomeworkAssignment)
content/<клас>/<предмет>/<тема>/teoria.mdx   # дълъг учебен текст (теория) към темата
src/lib/curriculum.ts    # достъп и помощни функции (getTopic, formatWeeks, toRoman…)
src/lib/materials.ts     # достъп до регистъра с материали
src/lib/theory.ts        # четене на teoria.mdx при build
src/data/games.ts        # регистър на учебните игри (раздел „Игри“, /igri)
public/games/<игра>.html # самостоятелна HTML игра, вграждана с iframe
```

Часовете са по 1 седмично в 36 учебни седмици: всяка тема обхваща 6 седмици с редуване „нечетна седмица — теория, четна — практика“. Всяка тема има собствена страница `/<клас>/<предмет>/<тема>` със секции: седмичен график по учебната програма, теория (MDX), практически задачи, домашна работа за самостоятелна подготовка (по една на двуседмичен цикъл — възлага се в седмицата с теория) и тест за самопроверка (изпитен режим, резултатът се пази в localStorage на ученика — без сървър и без лични данни).

### Добавяне на нов клас/предмет

1. Добавете обект в `curriculum.grades` (или запълнете `subjects` на съществуващ клас с `available: true`) в `src/data/curriculum.ts`.
2. Няма нужда от промени по страниците — маршрутите `/<клас>/<предмет>` и `/<клас>/<предмет>/<тема>`, началната страница, навигацията и sitemap-ът се генерират от данните.

### Добавяне на материали към тема

1. **Теория:** създайте `content/<клас>/<предмет>/<тема>/teoria.mdx` (Markdown + компонентът `<Callout type="info|tip|warn">`).
2. **Тест, задачи и домашна работа:** създайте `src/data/materials/<клас>/<предмет>/<тема>.ts` с обект `TopicMaterials` и го регистрирайте в `src/data/materials/index.ts`.
3. Страницата на темата показва автоматично наличното и обозначава останалото като „предстои“; на страницата на предмета се появяват отметки ✓.

### Учебни игри (раздел „Игри“)

Игрите са самостоятелни HTML файлове (собствен CSS и JS, без build стъпка). Страницата `/igri/<игра>` ги вгражда в iframe на цялата височина на екрана, с бутони „Цял екран“ (за проектор) и „Отвори в отделен раздел“, и показва бележки „За учителя“.

1. Сложете файла в `public/games/<игра>.html`. За да следва светлия/тъмния режим на сайта, в `<head>` трябва да има скрипт, който чете ключа `theme` от localStorage и задава `data-theme` на `<html>` (вижте `remont-na-bit.html`).
2. Добавете обект `Game` в `src/data/games.ts` (заглавие, предмет, понятия, `src`, бележки за учителя).
3. Каталогът `/igri`, страницата на играта, картата на началната страница и sitemap-ът се обновяват автоматично.
