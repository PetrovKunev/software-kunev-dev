# software.kunev.dev

Учебен сайт за паралелка **„Разработка на софтуер“** (професия код 061303, направление 0613) — материали по специалните предмети, подредени по класове, раздели, теми и седмици според официалната учебна програма.

**Продукция:** [software.kunev.dev](https://software.kunev.dev) (Vercel, deploy при push към `main`)

## Стек

- [Next.js](https://nextjs.org/) (App Router, статичен рендер)
- [Tailwind CSS 4](https://tailwindcss.com/) — cyber teal dark тема (токени в `src/app/globals.css`)
- TypeScript, без база данни и без auth — цялото съдържание е публично и статично

## Структура на съдържанието

Учебната програма се пази като структурирани TypeScript данни, не в JSX. Дългите учебни текстове са MDX файлове (хибриден модел):

```
src/data/types.ts        # модел: клас → предмет → раздел → тема → седмици + тест/задачи
src/data/curriculum.ts   # програмата: VIII клас · „Дигитални технологии“ (Раздели I–II, Теми 1–6)
src/data/materials/      # материали по теми: тест (Quiz) и практически задачи (PracticeTask)
content/<клас>/<предмет>/<тема>/teoria.mdx   # дълъг учебен текст (теория) към темата
src/lib/curriculum.ts    # достъп и помощни функции (getTopic, formatWeeks, toRoman…)
src/lib/materials.ts     # достъп до регистъра с материали
src/lib/theory.ts        # четене на teoria.mdx при build
```

Всяка тема има собствена страница `/<клас>/<предмет>/<тема>` със секции: учебна програма, теория (MDX), практически задачи и тест за самопроверка (изпитен режим, резултатът се пази в localStorage на ученика — без сървър и без лични данни).

### Добавяне на нов клас/предмет

1. Добавете обект в `curriculum.grades` (или запълнете `subjects` на съществуващ клас с `available: true`) в `src/data/curriculum.ts`.
2. Няма нужда от промени по страниците — маршрутите `/<клас>/<предмет>` и `/<клас>/<предмет>/<тема>`, началната страница, навигацията и sitemap-ът се генерират от данните.

### Добавяне на материали към тема

1. **Теория:** създайте `content/<клас>/<предмет>/<тема>/teoria.mdx` (Markdown + компонентът `<Callout type="info|tip|warn">`).
2. **Тест и задачи:** създайте `src/data/materials/<клас>/<предмет>/<тема>.ts` с обект `TopicMaterials` и го регистрирайте в `src/data/materials/index.ts`.
3. Страницата на темата показва автоматично наличното и обозначава останалото като „предстои“; на страницата на предмета се появяват отметки ✓.
